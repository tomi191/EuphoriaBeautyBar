# Ръчни миграции

`drizzle-kit push` не върви тук (виси на интроспекцията), а досегашните промени по базата са
отделни скриптове в `scripts/` без общ ред. От №8 Б1 новите промени са тук като чист SQL:

- `NNNN_<име>.sql`: прилагане. Само добавяне (`ADD COLUMN IF NOT EXISTS`, `CREATE INDEX IF NOT EXISTS`),
  в една транзакция, повторното пускане не чупи нищо.
- `NNNN_<име>.down.sql`: връщане назад.
- Схемата в `src/lib/db/schema.ts` се сменя в същия commit.

Прилага се с `psql "<адрес>" -v ON_ERROR_STOP=1 -f drizzle/manual/NNNN_<име>.sql`.
На живата база само с думата на собственика; проверката след това е `\d <таблица>`.

| Файл | Какво | Пробна база | Жива база |
|---|---|---|---|
| 0001_rental_listings | обявата за място под наем (`rental_positions`) и запитванията от нея (`rental_inquiries`) | 22.11.2026 | чака думата на собственика |
